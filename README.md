# Student Management System

This is an ASP.NET Core MVC web application created to manage student logs. It uses the EF Core Code-First approach for database operations.

## Technologies Used
- C# and ASP.NET Core MVC (.NET 8.0 / 6.0)
- Entity Framework Core
- SQL Server Database
- Bootstrap for UI Layout

## Features
- Full CRUD operations (Create, Read, Update, Delete) for Student data.
- Database created automatically using C# Code-First Migrations.
- Dependency Injection configuration in Program.cs.

## Setup Instructions
1. Open the project in Visual Studio 2022.
2. Update the connection string in appsettings.json.
3. Open Package Manager Console and run 'Update-Database'.
4. Run the project (F5).
